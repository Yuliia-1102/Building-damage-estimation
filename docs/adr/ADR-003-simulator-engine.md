# ADR-003. Симулятор із записаних кейсів для розробки і CI без Gemini

- **Статус:** прийнято 03.11.2026
- **Учасники:** Андрій Лисанець
- **Задачі:** Sprint 4 — A3; код: `core/simulator.py`, `tools/make_pack.py`, реліз v1.0 `devpack.zip`

## Контекст

Справжня обробка заявки потребує ваг моделі сегментації (~1 ГБ, PyTorch) і платного ключа Gemini.
Вебсистему одночасно розробляла людина без ключа, а автоматичні тести мають іти на кожен pull request у
GitHub Actions — там немає ні ваг, ні ключа, і кожен прогін коштував би грошей та давав би трохи різні
відповіді моделі.

## Розглянуті варіанти

1. **Тести з реальною моделлю й ключем у секретах CI.** Плюс: перевіряється справжній шлях.
   Мінус: гроші за кожен запуск, 15–55 с на кейс, нестабільні відповіді, ключ у ще одному місці.
2. **Заглушка, що повертає випадкові або фіксовані числа.** Плюс: просто. Мінус: формат результату, звіт,
   PDF, зображення масок — усе фіктивне; інтерфейс не бачить справжніх даних.
3. **Симулятор із записаних кейсів.** Один раз проганяємо тестовий набір на реальній моделі, записуємо входи
   й повні результати (звіт, маски, PDF). Симулятор має той самий інтерфейс `Engine`, впізнає завантажений
   файл за SHA-256 і повертає записаний результат; є затримка й режим збою для перевірки обробника.

## Рішення

Варіант 3. `DAMAGE_ENGINE=simulator` — режим розробки і CI; `DAMAGE_ENGINE=production` — робочий продукт
(лише з дозволу на виклик Gemini). Набір кейсів (`devpack.zip`, ~180 МБ) лежить у релізі v1.0, а не в git.

## Наслідки

**Позитивні**
- CI проганяє всі вебтести без ваг, ключа і грошей; результат детермінований.
- Розробник вебчастини працював на справжніх результатах, не маючи доступу до платного ключа.

**Негативні**
- Симулятор знає лише записані файли; нове фото в режимі симулятора не оцінюється.
- Кеш CI прив'язаний до ключа `devpack-v1.0`: якщо файл у релізі замінять, ключ треба змінити вручну
  (зауваження рецензента в PR #1, задокументовано в README).
- Справжня інтеграція перевіряється окремо (A5), а не в CI.

## Умова перегляду

Зміна формату результату `Engine.process()` або перехід на модель, яку можна запускати локально безкоштовно.
