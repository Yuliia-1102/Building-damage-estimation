# Sample price data (NOT real prices)

Same tables as the materials database (`work_type`, `material`, `work_material`, `price`) plus
labour prices, so the cost calculation and the tests run without the database. The numbers are
rough placeholders entered by the team to make the pipeline run end to end; they have no source
and must not be presented as a real estimate. Real prices with sources come from the materials
database (task "Initial data"). `work_types.csv` codes must match `core/reference.py`.
